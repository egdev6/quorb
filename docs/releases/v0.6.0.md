# Quorb 0.6.0 — Una interfaz más clara / A clearer interface

## Español

Consultad el consumo con ventanas emergentes mejor ajustadas y distinguid con
más facilidad las acciones que eliminan cuentas o credenciales.

### Mejorado

- Las ventanas de detalle al pasar el cursor ajustan su altura al contenido,
  evitando desplazamientos innecesarios.
- Los botones secundarios muestran su degradado también en reposo y usan un
  cambio de opacidad al pasar el cursor.
- Las acciones de eliminar cuentas, eliminar claves y desconectar se distinguen
  visualmente del resto de botones.
- Se han añadido comprobaciones automáticas de tests, compilación y secretos
  para las contribuciones. Las herramientas adicionales de análisis estático
  están preparadas, pero su nuevo workflow todavía no está activado.

### Importante e instalación

- Esta entrega corresponde a Quorb estable. Se ha retirado el canal experimental
  instalado Quorb Dev; no se incorpora como novedad ni se promete una migración
  automática de sus datos.
- Cuando se publique 0.6.0, descargad el EXE o MSI de Windows x64 desde su release.
  Mientras el repositorio siga privado, no se promete acceso anónimo a descargas
  ni actualizaciones automáticas. La apertura pública se realizará aparte.
- La firma del updater no es Authenticode: Windows puede mostrar avisos de
  SmartScreen. No desactivéis las protecciones para instalar la aplicación.
- Las pruebas automatizadas no sustituyen la comprobación del instalador,
  la instalación asistida de Codex, el login ni las credenciales en Windows.
  La generación y firma de los artefactos se comprobarán al ejecutar Release.
- Esta versión no añade limpieza completa de datos y credenciales al desinstalar
  ni revocación de sesiones OAuth.

## English

Check usage in better-sized hover panels and more easily distinguish actions
that remove accounts or credentials.

### Improved

- Hover detail panels adjust their height to their content, avoiding unnecessary
  scrolling.
- Secondary buttons display their gradient while idle and change opacity on hover.
- Account removal, key deletion and disconnect actions are visually distinct
  from other buttons.
- Automated tests, builds and secret scanning have been added for contributions.
  Additional static-analysis tools are prepared, but their new workflow is not
  enabled yet.

### Important and installation

- This is the stable Quorb release. The experimental installed Quorb Dev channel
  has been retired; it is not a new feature and automatic migration of its data
  is not promised.
- Once 0.6.0 is published, download its Windows x64 EXE or MSI from the release.
  While the repository remains private, anonymous downloads and automatic updates
  are not promised. Making the repository public is a separate step.
- Updater signing is not Authenticode: Windows may display SmartScreen warnings.
  Do not disable Windows protections to install the application.
- Automated tests do not replace checking the installer, assisted Codex
  installation, login or credentials on Windows. Artifact generation and signing
  will be checked when Release runs.
- This version does not add complete uninstall cleanup of app data and credentials
  or OAuth session revocation.
