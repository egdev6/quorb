# Quorb 0.8.0 — Primeros pasos en inglés y tres proveedores nuevos / First steps in English and three new providers

## Español

Usad Quorb con la interfaz en inglés en sus partes principales, seguid vuestro
consumo de MiniMax, z.ai y SuperGrok, y contad con un popup de detalle que se
comporta mejor en Windows.

### Nuevo

- Selector de idioma en Ajustes → Apariencia: podéis elegir entre español e
  inglés. El español sigue siendo el idioma por defecto.
- En inglés se muestran ya el menú de la bandeja, los títulos de las ventanas,
  la tira de anillos, el panel de detalle y las secciones de Ajustes Apariencia,
  Alertas, Atajos y Actualizaciones. Es una primera parte de la traducción.
- Proveedor MiniMax: anillo de uso de la cuota del plan y, si añadís también la
  API key de pago por uso, su saldo PAYG.
- Proveedor z.ai (GLM Coding Plan): cuotas de 5 h y semanal, cuota mensual de
  web tools y el número de resets disponibles.
- Proveedor SuperGrok: uso semanal de créditos de vuestra suscripción,
  reutilizando la sesión del Grok CLI oficial.

### Mejorado

- El cambio de idioma se aplica al momento, sin reiniciar Quorb: también el
  menú de la bandeja y los títulos de las ventanas abiertas.

### Corregido

- El popup de detalle ya no se vuelve a abrir solo cuando Windows devuelve el
  foco al anillo tras cerrarse. Sigue abriéndose al pasar el ratón, con clic
  y con el teclado.

### Importante e instalación

- Disponible para [Windows x64 (EXE)](https://github.com/egdev6/quorb/releases/download/v0.8.0/Quorb_0.8.0_x64-setup.exe)
  y [macOS 15+ con Apple Silicon, M1 o posterior (DMG)](https://github.com/egdev6/quorb/releases/download/v0.8.0/Quorb_0.8.0_aarch64.dmg).
  No hay descarga para Mac Intel ni release pública de Linux en esta versión.
- El DMG de macOS está firmado con Developer ID y notarizado por Apple; incluye
  [checksum SHA-256](https://github.com/egdev6/quorb/releases/download/v0.8.0/Quorb_0.8.0_aarch64.dmg.sha256).
  Abrid el DMG y copiad Quorb a Aplicaciones. Las actualizaciones macOS son manuales.
  La verificación de firma, ticket y Gatekeeper pasó en CI; la primera descarga
  por navegador, instalación y GUI en un Mac real siguen pendientes en
  [#118](https://github.com/egdev6/quorb/issues/118). No retiréis la cuarentena para eludir avisos.
- La interfaz en inglés aún no cubre toda la aplicación: las pestañas de
  proveedores, los botones comunes de Ajustes (Cerrar, Guardar cambios) y
  textos que llegan del backend, como mensajes y etiquetas largas de
  medidores, siguen en español.
- El proveedor SuperGrok usa un endpoint no oficial del Grok CLI: si su formato
  cambia, el anillo de SuperGrok puede mostrar un aviso o un error.
- Descargad el EXE o MSI de Windows x64 desde esta
  release. La firma del updater no es Authenticode: Windows puede mostrar
  avisos de SmartScreen. No desactivéis las protecciones para instalar la
  aplicación.
- Las pruebas automatizadas no sustituyen la comprobación del instalador, el
  login ni las credenciales en Windows. La publicación macOS se completó en
  [este resume verificado](https://github.com/egdev6/quorb/actions/runs/41233474221);
  ese resultado no acredita una prueba GUI en un Mac real.

## English

Use Quorb with its main parts in English, track your MiniMax, z.ai and
SuperGrok usage, and enjoy a detail popup that behaves better on Windows.

### New

- Language selector in Settings → Appearance: choose between Spanish and
  English. Spanish remains the default language.
- In English you already get the tray menu, the window titles, the ring strip,
  the detail panel and the Appearance, Alerts, Shortcuts and Updates sections
  of Settings. This is a first part of the translation.
- MiniMax provider: usage ring for the plan quota and, if you also add the
  pay-as-you-go API key, its PAYG balance.
- z.ai provider (GLM Coding Plan): 5 h and weekly quotas, monthly web tools
  quota and the number of available resets.
- SuperGrok provider: weekly credit usage of your subscription, reusing the
  official Grok CLI session.

### Improved

- Language changes apply right away, without restarting Quorb: the tray menu
  and the titles of open windows included.

### Fixed

- The detail popup no longer reopens by itself when Windows returns focus to
  the ring after it closes. It still opens with hover, click and keyboard.

### Important and installation

- Available for [Windows x64 (EXE)](https://github.com/egdev6/quorb/releases/download/v0.8.0/Quorb_0.8.0_x64-setup.exe)
  and [macOS 15+ on Apple Silicon, M1 or later (DMG)](https://github.com/egdev6/quorb/releases/download/v0.8.0/Quorb_0.8.0_aarch64.dmg).
  There is no Intel Mac download or public Linux release in this version.
- The macOS DMG is Developer ID signed and Apple notarized, with a
  [SHA-256 checksum](https://github.com/egdev6/quorb/releases/download/v0.8.0/Quorb_0.8.0_aarch64.dmg.sha256).
  Open the DMG and copy Quorb to Applications. macOS updates are manual.
  Signature, ticket and Gatekeeper checks passed in CI; first browser download,
  installation and GUI checks on a real Mac remain pending in
  [#118](https://github.com/egdev6/quorb/issues/118). Do not remove quarantine to bypass warnings.
- The English interface does not cover the whole application yet: the provider
  tabs, the shared Settings buttons (Close, Save changes) and texts coming from
  the backend, such as messages and long meter labels, are still in Spanish.
- The SuperGrok provider uses an unofficial Grok CLI endpoint: if its format
  changes, the SuperGrok ring may show a warning or an error.
- Download the Windows x64 EXE or MSI from this
  release. Updater signing is not Authenticode: Windows may display
  SmartScreen warnings. Do not disable Windows protections to install the
  application.
- Automated tests do not replace checking the installer, login or credentials
  on Windows. macOS publication completed in
  [this verified resume](https://github.com/egdev6/quorb/actions/runs/41233474221);
  that outcome does not establish a real-Mac GUI test.
